---
name: grill-me
description: Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree. Use when user wants to stress-test a plan, get grilled on their design, or mentions "grill me".
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer: the smallest shape that satisfies the ticket as written (often "use what's stored today"), with bigger shapes (new table, store, UI, permission model) listed as trade-ups. When challenged, separate ticket scope from option size instead of defending the option.

Write the draft shape first (types, fields, what each means) so every question points at it; a question I can only answer by imagining the shape is a sign the shape must come first.

If a question can be answered by exploring the codebase, explore the codebase instead.
